# 轻记账 (Bill PWA)

一个本地优先的轻量级移动端记账 PWA 应用。

## 功能

- 记录支出：选择类别、金额、备注、日期
- 支出类别：餐饮 / App订阅 / 日用 / 交通 / 学习 / 游戏 / 娱乐活动 / AI / 电子产品及配件 / 家庭开销 / 人情世故 / 恋爱支出 / 医疗健体
- 支付账户：微信支付 / 支付宝 / 银行卡 / 亲情卡
- 折线图：显示最近 7 天支出趋势（含零支出日）
- 数据存在手机本地（localStorage），不上传任何服务器
- 支持 CSV 智能导入、JSON 完整备份、Obsidian 同步导出
- 支持自定义快捷账单，一键记录固定支出
- 常用账单：按历史名称汇总，选择后填入最近一次的金额、分类和账户，修改金额后保存；输入完整历史名称也会自动匹配分类和账户
- 每月固定账单：设置金额、扣款日、开始日期，支持编辑、暂停和删除
- 支持添加到手机主屏幕（PWA），离线可用

## 使用方式

1. 打开 https://dagongzhanshi1.github.io/bill-pwa
2. 在浏览器中记账，或添加到手机主屏幕（iOS Safari → 分享按钮 → 添加到主屏幕）
3. 所有数据保存在手机本地，换浏览器/清缓存会丢失

## 数据存储

所有数据存在浏览器的 `localStorage` 中：
- key: `ledger_records` — 全部账单记录（JSON 数组）
- key: `ledger_categories` — 支出类别列表
- key: `ledger_accounts` — 支付账户列表
- key: `ledger_shortcuts` — 快捷账单模板
- key: `ledger_recurring` — 固定月度账单规则及下次记账日期
- key: `ledger_frequent_templates` — 从流水 MD 提取的常用项目（不是历史账单）

**注意：** 数据完全本地化，换设备、清缓存、使用隐私模式都会丢失数据。建议定期导出 JSON 完整备份；CSV 适合账单合并导入，JSON 适合完整恢复账单、分类、账户和快捷账单。

## 存储位置与主题启动

- 账单和设置存储在当前设备、当前浏览器/主屏幕 Web App 的本地网站存储中；线上站点的 origin 是 `https://dagongzhanshi1.github.io`，不是 GitHub 仓库内的文件。手机系统管理实际磁盘位置，无法通过“文件”App 直接打开数据库。不同浏览器、设备、本地预览和线上地址不应视为同一份数据。
- 公开版本不预置个人账单。全新浏览器首次访问时账单和常用项目为空，由使用者自行记账或导入；同一浏览器再次打开会保留自己的记录。不同浏览器的本地数据不通过本站互相同步。此前载入个人账单的 `127.0.0.1` 演示不属于 GitHub Pages 发布内容。
- `ledger_records` 保存账单，`ledger_theme` 保存主题，其他存储 key 见上文；不会自动把账单同步到 GitHub 或 iCloud 文件夹，只有导出的 CSV/JSON/MD 才是独立文件。
- 离线软件资源单独保存在 Cache Storage，当前缓存为 `ledger-v9`，内容是首页、`bill-tools.js`、manifest 和图标，不是账单数据库；浏览器还可能管理普通 HTTP 缓存。
- 更新代码和升级离线缓存不清除账单。不要通过清除整个网站数据解决主题或更新问题；删除网站数据会影响本地账单，先导出 JSON 备份。
- 主题在 `<head>` 内同步恢复，CSS 在根节点读取主题，避免等待外部脚本时先显示默认绿色；浏览器的主题色 meta 同步更新。操作系统启动画面不属于网页渲染，其外观仍由系统与安装信息管理。

## 常用项目与每月记账

- 首页的常用账单区展示所有项目，包括只记过一次的项目，按次数从多到少排序，同次数按最近记录优先；列表可滚动，“全部”可搜索。点选只填单，不直接保存，修改价格后再保存。名称按明确的同音别名及商家名称归一统计，分类、账户和参考金额取最近一次记录，仍可手动修改。
- 设置 → 常用账单 → 从流水 MD 提取：可选择本应用的 Obsidian 导出文件，只在当前浏览器保存项目摘要，不导入账单，不上传文件。同名项目优先使用当前本地记录；重复提取同一文件不会叠加次数。
- 固定账单只生成支出记录，不会发起真实扣款。每月 29/30/31 日遇到短月份时按月末记账。
- 创建规则时默认从今天开始；选过去日期会确认是否补记。应用启动、回到前台和前台每分钟检查到期项目，按规则和月份防止重复。网页关闭时不能可靠后台记账，下次打开补记。
- 已有同日同名同金额同分类同账户账单时视为已记。删除自动账单不会在当月立即重新生成；暂停后恢复只从恢复当天起继续，暂停期间不补记。编辑不会回写已生成的历史账单。
- 此次改动保持 `ledger_records` 不变，不清空历史数据。上线前建议在手机导出完整 JSON 备份。
- 设置 → 统一历史账单名称：确认后只改每笔名称，保留数量、金额、日期、分类及账户，原名称追加到备注。不会把多笔记录压成一笔。整理前自动在 `ledger_before_name_cleanup` 保存完整 JSON 快照，可在设置里导出并通过恢复 JSON 备份恢复；再次整理前的快照会替换上一份快照，需长期保留时先导出。
- 新增记录、常用汇总按同一套名称规则处理。规则包含金小月/金晓月 → 金小悦、原麦田/源麦田、赵一铭/赵一鸣等明确别名；同商家餐品写法可统一到商家，但不会自动推测所有未知名称的同音关系。
- 经确认统一的项目还包括：超市盒马/盒马生鲜 → 盒马，洗衣服 → 兰德力自助洗，滴滴打车 → 打车，网吧 → 网鱼网吧，餐巾纸 → 纸巾，夸克网盘svip → 夸克会员，两种鸭腿饭配饮料写法 → 鸭腿饭，茉莉清茶/茉莉花茶无糖 → 茉莉花茶。其余未确认的候选项目保持区分。
- `node scripts/normalize-ledger.cjs /绝对路径/流水.md` 会在源文件旁生成名称整理版与变更清单，原文件不变；逐笔验证金额、日期、时间、分类及账户，已有同名输出时拒绝覆盖。整理版不要再次追加到已有 Obsidian 流水，以免旧导入插件因名称变化漏判重复。

## 测试

运行 `node --test tests/bill-tools.test.cjs`。

浏览器回归：安装 Playwright 后运行 `node tests/app-smoke.cjs`（默认使用 macOS Chrome，可通过 `CHROME_PATH` 指定浏览器）。可用 `BILL_TEST_MD` 指向本地流水文件做提取测试，测试不修改源文件或真实浏览器数据。

首次访问与隔离回归：`node tests/privacy-first-run.cjs https://dagongzhanshi1.github.io/bill-pwa/`。使用两个临时浏览器环境，验证首次访问为空、自己的数据能保留、另一个独立环境读取不到测试记录，不操作真实浏览器数据。
